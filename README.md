# Dynamic Form Builder - Premium UI

Run `index.html` using VS Code Live Server.

## Main features
- Text, number, date, checkbox, and dropdown fields
- Click and drag-and-drop field creation
- Live preview
- Property editing and validation
- Conditional show/hide/disable rules
- Dropdown option editor
- Undo and redo
- Save and load from Local Storage
- Export and import JSON
- Light and dark themes
- Responsive layout
